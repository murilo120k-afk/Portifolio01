# Koncorp Industries — IA Assistente Pessoal Inteligente

Projeto institucional fictício desenvolvido para apresentação de uma empresa de tecnologia focada em inteligência artificial, automação pessoal e apoio à produtividade.

## Descrição

O site apresenta a **Koncorp Industries**, uma empresa voltada ao desenvolvimento de soluções em **IA assistente pessoal inteligente**, com foco em organização, automação de tarefas, monitoramento e apoio à tomada de decisão.

O projeto foi estruturado em páginas separadas para facilitar a navegação e organizar melhor o conteúdo institucional.

## Objetivo

O objetivo deste projeto é criar um site moderno, simples e responsivo para apresentar:

- a identidade da empresa;
- os serviços oferecidos;
- aplicações práticas da solução;
- informações de contato;
- e a proposta principal do sistema.

## Tecnologias utilizadas

- **HTML5**
- **CSS3**
